## 📌 About the Project

MemberPass is a web-based membership management application developed to make membership-related activities smarter, faster, and more convenient.

The platform brings together digital membership passes, QR-based attendance management, membership plans, payment-related services, and AI-powered capabilities in one application.

It provides dedicated experiences for members and staff through a modern and responsive interface.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

### 2. Navigate to the Project

```bash
cd MemberPass
```

### 3. Install Frontend Dependencies

```bash
cd frontend
npm install
```

### 4. Configure Frontend Environment

Create a `.env` file inside the frontend folder:

```env
VITE_API_URL=https://memberpass-gdur.onrender.com/api
```

### 5. Start the Frontend

```bash
npm run dev
```

The frontend will be available at:

```text
http://localhost:5173
```

### 6. Install Backend Dependencies

Open another terminal:

```bash
cd backend
npm install
```

### 7. Configure Backend Environment

Create a `.env` file inside the backend folder:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
NODE_ENV=development
```

Add any additional environment variables required by your configured services.

### 8. Start the Backend

```bash
npm run dev
```

The backend will run on:

```text
http://localhost:5000
```
